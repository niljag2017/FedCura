S1

Centralized Baseline

All data pooled · oracle upper bound

AUROC 0.803

All 2,119 patient records from 186 hospitals are pooled on one server. LR is trained with 5-fold stratified cross-validation, then the fitted model is evaluated on the shared held-out test set. No privacy guarantee — raw records cross boundaries — but defines the maximum AUROC federated strategies must match.

Centralised LR objective · strategies.py run_centralized()
Objective: min_w L(w) = Σᵢ ℓ(wᵀxᵢ, yᵢ) + λ‖w‖² where: ℓ = log-loss λ = 1/C = 100 (C=0.01, strong L2 regularisation) class_weight = 'balanced' (corrects 16.9% positive rate) solver = 'lbfgs' · max_iter = 2000 Validation: StratifiedKFold(n_splits=5) → CV AUROC global_test.evaluate(model) → held-out AUROC ← primary metric Weight shape: coef_ = (1 × 23) · intercept_ = (1,)

S2

FedAvg Region

4 US Census regions · McMahan et al. 2017

AUROC 0.803

Hospitals are partitioned by US Census region (NE, MW, S, W). Each region trains a local LR, warm-starting from the global weight vector. The server does weighted FedAvg — averaging coef_ (1×23) proportional to each region's n_train. Best privacy-preserving result: matches the centralised oracle exactly.

FedAvg · models.py fedavg_aggregate()
Round t (t = 1 … fl_rounds=3): Server broadcasts w_global → all K=4 regions Each region k: inject_weights(model_k, w_global) # warm-start model_k.fit(X_k_train, y_k_train) w_k = extract_weights(model_k) # coef_ (1×23) FedAvg aggregate: α_k = n_k / N # N = Σ n_k w_global = Σ_k α_k · w_k Evaluate global model on 424-patient held-out test set

S3

Cluster FedAvg

K-Means hospital clustering · k=3

AUROC 0.755

A per-hospital feature vector (median APACHE, ICU LOS, readmission rate, bed size) is computed, then K-Means (k=3) groups clinically similar hospitals. Each cluster trains as one FL client and contributes to a standard FedAvg update.

S4

Quality-Gated Hospital FL

Per-hospital · two-phase screening

AUROC 0.740

Phase 1: size filter (n≥10, pos≥2, neg≥2) then one screening round measures each hospital's local AUROC. Only hospitals that pass the gate (≥0.55) enter Phase 2 FedAvg. On the demo most hospitals are too small; full eICU expected to rank highest with this strategy.

Quality-gated FedAvg · strategies.py run_hospital_federation()
Phase 1 — Size screening: Admit hospital h iff: n_h ≥ 10 ∧ n_pos_h ≥ 2 ∧ n_neg_h ≥ 2 Phase 1 — AUROC gate (fl_rounds=1): For each candidate h: w_h ← LocalTrain(w_global, D_h) auroc_h = roc_auc_score(y_val_h, ŷ_h) if auroc_h ≥ τ (τ=0.55) → Q ← Q ∪ {h} Phase 2 — FedAvg on qualified set Q: w_global = Σ_{h∈Q} (n_h / N_Q) · w_h Params: auroc_gate=0.55 · min_hospital_stays=10

S5

FedProx

Regions + proximal regularisation · Li et al. 2020

AUROC 0.803

Extends FedAvg Region (S2) with a proximal term penalising client weights from drifting far from the global model. For LR the update is a closed-form interpolation. On the demo dataset S5 ≈ S2 — heterogeneity is not severe enough for the proximal term to matter at this scale.

FedProx local objective · client.py local_train()
Local minimise per region k: F_k(w) + (μ/2) · ‖w − w_global‖² μ = 0 → standard FedAvg (S2) μ → 1 → local weights pulled to global model LR closed-form proximal update: model_k.fit(X_k, y_k) # standard local fit w_k ← (1−μ) · w_local + μ · w_global μ = min(fedprox_mu, 1.0) = 0.01 Aggregate (identical to S2): w_global = Σ_k (n_k / N) · w_k
client.py · local_train() — FedProx proximal step
if (self.fedprox_mu > 0 and global_weights.get("type") == "lr" and self.algorithm == "logistic_regression"): self.model.fit(X_tr, y_tr) local_coef = self.model.coef_.copy() global_coef = np.array(global_weights["coef"]) # w ← (1−μ)w_local + μ·w_global mu = min(self.fedprox_mu, 1.0) # 0.01 self.model.coef_ = ((1 - mu) * local_coef + mu * global_coef) else: self.model.fit(X_tr, y_tr)

S6

Non-IID Simulation

Dirichlet label distribution · Li et al. 2021

AUROC 0.722

Dirichlet(α=0.5) partitioning creates 5 synthetic clients with skewed label distributions, simulating realistic hospital heterogeneity. FedAvg then runs on these synthetic silos. AUROC drops with lower α — this stress-tests robustness and demonstrates the real cost of data heterogeneity.

Dirichlet non-IID partition · data.py dirichlet_partition()
Partition training data into K=5 synthetic clients: For each class c ∈ {0, 1}: p_c ~ Dirichlet(α · 1_K) # proportion vector assign p_c[k] fraction of class-c rows → client k α = 0.5 → moderate label skew α → 0 → extreme heterogeneity α → ∞ → IID (uniform distribution) FedAvg proceeds as in S2: w_global = Σ_k (n_k / N) · w_k Params: α=0.5 · K=5 clients · fl_rounds=3
